# Playroom downloads

Fullscreen Windows game launcher for Windows 10/11 x64.

[Download the latest Windows installer](https://github.com/wired-nick/Playroom-Releases/releases/latest/download/PlayroomLauncher-win-Setup.exe) · [All releases](https://github.com/wired-nick/Playroom-Releases/releases)

Install this update-enabled version once on each PC and use the new Playroom shortcut. Future published versions are checked and installed when Playroom starts. If the PC is offline, the installed version still opens.

Your existing library, artwork and preferences remain in your Windows account. On a new PC, controller compatibility is set up separately in Settings → Controllers and may require Windows approval and a restart. Ordinary app updates do not install drivers.

The installed version appears in Settings, About and the startup splash. The Playroom installer is currently unsigned; bundled controller drivers retain their upstream signatures.

This repository contains downloadable builds and update metadata. Application source is maintained separately. SHA-256 checksum files accompany downloads.
